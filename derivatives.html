Derivatives: The Heart of Deep Learning

Introduction

The derivative is perhaps the most important concept in machine learning. Every time a neural network learns, it's computing derivatives. Understanding derivatives deeply is essential for:

Why Derivatives Matter for ML:
  • Backpropagation: The algorithm that trains neural networks is just the chain rule applied repeatedly
  • Gradient Descent: Optimization uses derivatives to find parameter values that minimize loss
  • Understanding Convergence: Second derivatives tell us about the shape of the loss landscape
  • Feature Importance: Derivatives show how sensitive outputs are to inputs

Definition of the Derivative

Definition: Derivative

The derivative of a function \( f \) at a point \( x \) is defined as:

\[ f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} \]

provided this limit exists.

Geometric Interpretation: The derivative \( f'(x) \) represents the slope of the tangent line to the curve \( y = f(x) \) at the point \( (x, f(x)) \).

Physical Interpretation: If \( f(t) \) represents position at time \( t \), then \( f'(t) \) represents velocity (rate of change of position).

ML Interpretation: If \( L(\theta) \) is the loss as a function of parameter \( \theta \), then \( \frac{dL}{d\theta} \) tells us how much the loss changes when we change the parameter — this guides optimization!

Derivative at x = 0

Differentiation Rules

Basic Differentiation Rules

Function Derivative ML Relevance
\( f(x) = c \) \( f'(x) = 0 \) Bias terms
\( f(x) = x^n \) \( f'(x) = nx^{n-1} \) Polynomial features
\( f(x) = e^x \) \( f'(x) = e^x \) Exponential models
\( f(x) = \ln(x) \) \( f'(x) = \frac{1}{x} \) Log loss
\( f(x) = \sin(x) \) \( f'(x) = \cos(x) \) Periodic features
\( f(x) = \cos(x) \) \( f'(x) = -\sin(x) \) Periodic features

Combination Rules

  1. Sum Rule: \( (f + g)' = f' + g' \)
  2. Constant Multiple Rule: \( (cf)' = cf' \)
  3. Product Rule: \( (fg)' = f'g + fg' \)
  4. Quotient Rule: \( \left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2} \)

Example: Find the derivative of \( f(x) = x^2 e^x \)

Using the product rule:

\[ \begin{align*} f'(x) &= (x^2)' e^x + x^2 (e^x)' \\ &= 2x e^x + x^2 e^x \\ &= e^x(2x + x^2) \end{align*} \]

The Chain Rule: Heart of Backpropagation

Chain Rule

If \( y = f(u) \) and \( u = g(x) \), then:

\[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} \]

Or equivalently: \( (f \circ g)'(x) = f'(g(x)) \cdot g'(x) \)

🧠 This is Backpropagation!

In neural networks, the output is a composition of many functions (layers). The chain rule lets us compute how the loss changes with respect to each parameter by multiplying derivatives backward through the network.

Example 1: Find the derivative of \( h(x) = (x^2 + 1)^5 \)

Let \( u = x^2 + 1 \), so \( h(x) = u^5 \)

\[ \begin{align*} h'(x) &= \frac{d}{dx}[u^5] = \frac{d}{du}[u^5] \cdot \frac{du}{dx} \\ &= 5u^4 \cdot 2x \\ &= 5(x^2 + 1)^4 \cdot 2x \\ &= 10x(x^2 + 1)^4 \end{align*} \]

Example 2: Neural Network Layer

Consider a single neuron: \( y = \sigma(wx + b) \) where \( \sigma \) is sigmoid.

To find \( \frac{dy}{dw} \):

\[ \frac{dy}{dw} = \frac{dy}{d(wx+b)} \cdot \frac{d(wx+b)}{dw} = \sigma'(wx + b) \cdot x \]

This is exactly what backpropagation computes!

Multi-Layer Chain Rule

For a 3-layer network: \( L = f_3(f_2(f_1(x))) \)

\[ \frac{dL}{dx} = \frac{dL}{df_3} \cdot \frac{df_3}{df_2} \cdot \frac{df_2}{df_1} \cdot \frac{df_1}{dx} \]

Each \( \frac{df_i}{df_{i-1}} \) involves the derivative of the activation function — this is why we need differentiable activations!

Higher-Order Derivatives

The second derivative \( f''(x) \) is the derivative of the derivative. It tells us about the curvature of the function.

Concavity Test

  • If \( f''(x) > 0 \), the function is concave up (curves upward)
  • If \( f''(x) < 0 \), the function is concave down (curves downward)
  • If \( f''(x) = 0 \), we have a possible inflection point
ML Application: Second-Order Optimization

The second derivative (or Hessian in multiple dimensions) gives us information about the curvature of the loss landscape:

  • Positive curvature: We're in a valley — good for optimization!
  • Negative curvature: We're on a hill — need to be careful
  • Newton's Method: Uses second derivatives for faster convergence

Example: For \( f(x) = x^3 - 3x^2 + 2 \)

  • First derivative: \( f'(x) = 3x^2 - 6x \)
  • Second derivative: \( f''(x) = 6x - 6 = 6(x - 1) \)
  • Concave up when \( x > 1 \) (positive curvature)
  • Concave down when \( x < 1 \) (negative curvature)
  • Inflection point at \( x = 1 \)

Automatic Differentiation

Modern deep learning frameworks (PyTorch, TensorFlow) use automatic differentiation (autodiff) to compute derivatives. Unlike symbolic differentiation or numerical approximation, autodiff is:

  • Exact: No numerical errors like finite differences
  • Efficient: Computes derivatives in one backward pass
  • Automatic: You don't manually derive gradients

Forward Mode vs Reverse Mode

Forward Mode: Computes derivatives from inputs to outputs. Good when you have few inputs and many outputs.

Reverse Mode (Backpropagation): Computes derivatives from outputs to inputs. Perfect for neural networks where we have many parameters (inputs) but one loss (output)!

Why Reverse Mode for Deep Learning?

Neural networks typically have millions of parameters but a single scalar loss. Reverse mode autodiff computes gradients for all parameters in one backward pass — much more efficient than forward mode!

Gradient Descent: Derivatives in Action

Gradient descent is the workhorse algorithm for training neural networks. It uses derivatives to iteratively improve parameters:

\[ \theta_{new} = \theta_{old} - \alpha \frac{dL}{d\theta} \]

where:

  • \( \theta \) = parameters (weights, biases)
  • \( L \) = loss function
  • \( \alpha \) = learning rate (step size)
  • \( \frac{dL}{d\theta} \) = gradient (direction of steepest ascent)

Why Does It Work?

The gradient \( \nabla L \) points in the direction of steepest increase of the loss. By moving in the opposite direction (negative gradient), we move toward lower loss!

Taylor approximation explains it:

\[ L(\theta + \Delta\theta) \approx L(\theta) + \nabla L(\theta)^T \Delta\theta \]

To decrease \( L \), we want \( \nabla L(\theta)^T \Delta\theta < 0 \). Choosing \( \Delta\theta = -\alpha \nabla L(\theta) \) guarantees this!

Variants of Gradient Descent

  • Batch GD: Uses all training data — slow but stable
  • Stochastic GD (SGD): Uses one sample — fast but noisy
  • Mini-batch GD: Uses small batches — best of both worlds
  • Momentum: Accumulates past gradients for smoother updates
  • Adam: Adaptive learning rates per parameter — very popular!

Python Examples

Computing Derivatives Numerically

import numpy as np
import matplotlib.pyplot as plt

def numerical_derivative(f, x, h=1e-7):
    """
    Compute derivative using finite differences.
    f'(x) ≈ (f(x+h) - f(x-h)) / (2h)
    """
    return (f(x + h) - f(x - h)) / (2 * h)

# Example function
f = lambda x: x**3 - 3*x**2 + 2
f_prime_exact = lambda x: 3*x**2 - 6*x  # Exact derivative

# Compare numerical vs exact
x = 2.0
numerical = numerical_derivative(f, x)
exact = f_prime_exact(x)

print(f"Numerical derivative at x={x}: {numerical:.10f}")
print(f"Exact derivative at x={x}: {exact:.10f}")
print(f"Error: {abs(numerical - exact):.2e}")

Implementing Backpropagation from Scratch

import numpy as np

class SimpleNeuralNet:
    """
    Simple 2-layer network: input -> hidden -> output
    Demonstrates backpropagation (chain rule!)
    """

    def __init__(self, input_size, hidden_size, output_size):
        # Initialize weights randomly
        self.W1 = np.random.randn(input_size, hidden_size) * 0.01
        self.b1 = np.zeros((1, hidden_size))
        self.W2 = np.random.randn(hidden_size, output_size) * 0.01
        self.b2 = np.zeros((1, output_size))

    def sigmoid(self, x):
        return 1 / (1 + np.exp(-x))

    def sigmoid_derivative(self, x):
        """Derivative of sigmoid: σ'(x) = σ(x)(1 - σ(x))"""
        s = self.sigmoid(x)
        return s * (1 - s)

    def forward(self, X):
        """Forward pass - save intermediates for backprop"""
        self.z1 = X.dot(self.W1) + self.b1  # Pre-activation
        self.a1 = self.sigmoid(self.z1)      # Activation

        self.z2 = self.a1.dot(self.W2) + self.b2
        self.a2 = self.sigmoid(self.z2)      # Output

        return self.a2

    def backward(self, X, y, learning_rate=0.1):
        """
        Backpropagation - apply chain rule to compute gradients
        """
        m = X.shape[0]  # Number of samples

        # Output layer gradients
        # dL/dz2 = dL/da2 * da2/dz2
        dz2 = self.a2 - y  # For MSE loss with sigmoid
        dW2 = (1/m) * self.a1.T.dot(dz2)
        db2 = (1/m) * np.sum(dz2, axis=0, keepdims=True)

        # Hidden layer gradients (chain rule!)
        # dL/dz1 = dL/da2 * da2/dz2 * dz2/da1 * da1/dz1
        dz1 = dz2.dot(self.W2.T) * self.sigmoid_derivative(self.z1)
        dW1 = (1/m) * X.T.dot(dz1)
        db1 = (1/m) * np.sum(dz1, axis=0, keepdims=True)

        # Update weights (gradient descent)
        self.W1 -= learning_rate * dW1
        self.b1 -= learning_rate * db1
        self.W2 -= learning_rate * dW2
        self.b2 -= learning_rate * db2

    def train(self, X, y, epochs=1000, learning_rate=0.1):
        """Training loop"""
        losses = []

        for epoch in range(epochs):
            # Forward pass
            output = self.forward(X)

            # Compute loss (MSE)
            loss = np.mean((output - y)**2)
            losses.append(loss)

            # Backward pass
            self.backward(X, y, learning_rate)

            if epoch % 100 == 0:
                print(f"Epoch {epoch}, Loss: {loss:.6f}")

        return losses

# Example: XOR problem
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
y = np.array([[0], [1], [1], [0]])

# Create and train network
nn = SimpleNeuralNet(input_size=2, hidden_size=4, output_size=1)
losses = nn.train(X, y, epochs=5000, learning_rate=0.5)

# Test
predictions = nn.forward(X)
print("\nPredictions:")
print(predictions)
print("\nTargets:")
print(y)

Using PyTorch Autodiff

import torch
import torch.nn as nn

# Define a simple function
x = torch.tensor([2.0], requires_grad=True)
y = x**3 - 3*x**2 + 2

# Compute gradient automatically
y.backward()

print(f"x = {x.item()}")
print(f"y = f(x) = {y.item()}")
print(f"dy/dx = {x.grad.item()}")
print(f"Exact: 3x² - 6x = {3*x.item()**2 - 6*x.item()}")

# More complex example: neural network
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(10, 50)
        self.fc2 = nn.Linear(50, 1)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x

# Create network and dummy data
net = Net()
x = torch.randn(5, 10)  # Batch of 5 samples
y_true = torch.randn(5, 1)

# Forward pass
y_pred = net(x)
loss = ((y_pred - y_true)**2).mean()

# Backward pass - PyTorch computes all gradients!
loss.backward()

# Check gradients
for name, param in net.named_parameters():
    print(f"{name}: gradient shape = {param.grad.shape}")

Visualizing Gradient Descent

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def visualize_gradient_descent_2d():
    """
    Visualize GD on a 2D function
    """
    # Define function and gradient
    f = lambda x: x**2 + 10*np.sin(x)
    grad_f = lambda x: 2*x + 10*np.cos(x)

    # Gradient descent
    x = 5.0  # Starting point
    learning_rate = 0.1
    history = [x]

    for _ in range(50):
        x = x - learning_rate * grad_f(x)
        history.append(x)

    # Plot
    x_plot = np.linspace(-6, 6, 500)
    y_plot = f(x_plot)

    plt.figure(figsize=(12, 5))

    # Function and path
    plt.subplot(1, 2, 1)
    plt.plot(x_plot, y_plot, 'b-', linewidth=2, label='f(x)')
    plt.plot(history, [f(x) for x in history],
             'ro-', markersize=5, label='GD path')
    plt.xlabel('x')
    plt.ylabel('f(x)')
    plt.title('Gradient Descent on f(x) = x² + 10sin(x)')
    plt.legend()
    plt.grid(True, alpha=0.3)

    # Convergence
    plt.subplot(1, 2, 2)
    plt.plot([f(x) for x in history], 'g-o', markersize=3)
    plt.xlabel('Iteration')
    plt.ylabel('f(x)')
    plt.title('Function Value Over Time')
    plt.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

visualize_gradient_descent_2d()

Exercise 3: ML Application

Consider the sigmoid function \( \sigma(x) = \frac{1}{1 + e^{-x}} \):

  1. Prove that \( \sigma'(x) = \sigma(x)(1 - \sigma(x)) \)
  2. Why is this formula computationally efficient in neural networks?
  3. For a neuron \( y = \sigma(wx + b) \), find \( \frac{dy}{dw} \)
  4. What happens to \( \sigma'(x) \) when \( x \) is very large or very small? What does this mean for learning?
  1. \[ \begin{align*} \sigma'(x) &= \frac{d}{dx}\left[\frac{1}{1 + e^{-x}}\right] \\ &= \frac{0 \cdot (1 + e^{-x}) - 1 \cdot (-e^{-x})}{(1 + e^{-x})^2} \\ &= \frac{e^{-x}}{(1 + e^{-x})^2} \\ &= \frac{1}{1 + e^{-x}} \cdot \frac{e^{-x}}{1 + e^{-x}} \\ &= \frac{1}{1 + e^{-x}} \cdot \frac{(1 + e^{-x}) - 1}{1 + e^{-x}} \\ &= \sigma(x)(1 - \sigma(x)) \end{align*} \]
  2. We already computed \( \sigma(x) \) in the forward pass, so we can reuse it instead of recomputing exponentials!
  3. \( \frac{dy}{dw} = \sigma'(wx + b) \cdot x = \sigma(wx + b)(1 - \sigma(wx + b)) \cdot x \)
  4. When \( |x| \) is large, \( \sigma'(x) \to 0 \) (vanishing gradient problem!). This means neurons with large inputs learn very slowly.
