Multivariable Calculus: The Mathematics of Deep Learning

Introduction

Multivariable calculus extends derivatives and integrals to functions of multiple variables. This is absolutely essential for machine learning because:

  • Neural networks have millions of parameters — all optimized simultaneously
  • Loss functions depend on all parameters: \( L(\mathbf{w}, \mathbf{b}) \)
  • Gradients generalize derivatives to multiple dimensions
  • Hessians capture second-order information for advanced optimization

Partial Derivatives

Definition: Partial Derivative

For a function \( f(x, y) \), the partial derivatives are:

\[ \frac{\partial f}{\partial x} = \lim_{h \to 0} \frac{f(x+h, y) - f(x, y)}{h} \]

\[ \frac{\partial f}{\partial y} = \lim_{h \to 0} \frac{f(x, y+h) - f(x, y)}{h} \]

Interpretation: Partial derivative w.r.t. \(x\) measures how \(f\) changes when only \(x\) varies (keeping \(y\) fixed).

Example: For \( f(x, y) = x^2y + 3xy^2 \)

\[ \frac{\partial f}{\partial x} = 2xy + 3y^2 \quad \text{(treat } y \text{ as constant)} \]

\[ \frac{\partial f}{\partial y} = x^2 + 6xy \quad \text{(treat } x \text{ as constant)} \]

Gradient Vector

Definition: Gradient

The gradient of \( f: \mathbb{R}^n \to \mathbb{R} \) is the vector of all partial derivatives:

\[ \nabla f = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \frac{\partial f}{\partial x_2} \\ \vdots \\ \frac{\partial f}{\partial x_n} \end{bmatrix} \]

🎯 ML Connection: The gradient \( \nabla_\theta L(\theta) \) points in the direction of steepest increase of the loss. Gradient descent moves in the opposite direction: \( \theta \leftarrow \theta - \alpha \nabla_\theta L \)

Properties of the Gradient

  • Direction: Points in direction of steepest ascent
  • Magnitude: Rate of increase in that direction
  • Perpendicular to level curves: Gradient is always perpendicular to contours

Example: For \( f(x, y) = x^2 + y^2 \) (a paraboloid):

\[ \nabla f = \begin{bmatrix} 2x \\ 2y \end{bmatrix} \]

At point \((1, 2)\): \( \nabla f(1, 2) = \begin{bmatrix} 2 \\ 4 \end{bmatrix} \)

This vector points away from the origin (the minimum)!

Jacobian Matrix

When we have a vector-valued function \( \mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m \), we need the Jacobian:

Definition: Jacobian

\[ J = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \frac{\partial f_1}{\partial x_2} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \frac{\partial f_2}{\partial x_1} & \frac{\partial f_2}{\partial x_2} & \cdots & \frac{\partial f_2}{\partial x_n} \\ \vdots & \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \frac{\partial f_m}{\partial x_2} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix} \]

ML Application: In a neural network layer \( \mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b} \), the Jacobian \( \frac{\partial \mathbf{y}}{\partial \mathbf{x}} = \mathbf{W} \). The Jacobian appears everywhere in backpropagation!

Hessian Matrix

The Hessian contains all second-order partial derivatives:

Definition: Hessian

\[ H = \begin{bmatrix} \frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \cdots \\ \frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \cdots \\ \vdots & \vdots & \ddots \end{bmatrix} \]

ML Applications:
  • Newton's Method: Uses Hessian for second-order optimization
  • Curvature Information: Eigenvalues tell us about the loss landscape shape
  • Saddle Points: Hessian helps distinguish minima from maxima from saddle points

Example: For \( f(x, y) = x^2 + xy + y^2 \)

\[ H = \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix} \]

Both eigenvalues are positive → function is convex → gradient descent will converge!

Chain Rule in Multiple Dimensions

This is the mathematical foundation of backpropagation!

Multivariable Chain Rule

If \( z = f(x, y) \), \( x = g(t) \), and \( y = h(t) \), then:

\[ \frac{dz}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} \]

Backpropagation Example:

Consider: Input \( x \) → Layer 1 \( z_1 = \sigma(w_1 x) \) → Layer 2 \( z_2 = \sigma(w_2 z_1) \) → Loss \( L \)

To find \( \frac{\partial L}{\partial w_1} \):

\[ \frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial z_1} \cdot \frac{\partial z_1}{\partial w_1} \]

This is the chain rule! We compute it backward from loss to parameters.

Python Examples

Computing Gradients with NumPy

import numpy as np
import matplotlib.pyplot as plt

def numerical_gradient(f, x, h=1e-5):
    """
    Compute gradient numerically using finite differences.
    f: function R^n -> R
    x: point (numpy array)
    Returns: gradient vector
    """
    grad = np.zeros_like(x)
    for i in range(len(x)):
        x_plus = x.copy()
        x_minus = x.copy()
        x_plus[i] += h
        x_minus[i] -= h
        grad[i] = (f(x_plus) - f(x_minus)) / (2 * h)
    return grad

# Example: f(x,y) = x^2 + y^2
f = lambda x: x[0]**2 + x[1]**2
point = np.array([3.0, 4.0])
grad = numerical_gradient(f, point)
print(f"Gradient at {point}: {grad}")  # Should be [6, 8]

# Verify with exact gradient
exact_grad = 2 * point
print(f"Exact gradient: {exact_grad}")
print(f"Error: {np.linalg.norm(grad - exact_grad)}")

Gradient Descent in 2D

def gradient_descent_2d(f, grad_f, x0, lr=0.1, iters=100):
    """
    2D gradient descent visualization
    """
    x = x0.copy()
    history = [x.copy()]
    
    for _ in range(iters):
        grad = grad_f(x)
        x = x - lr * grad
        history.append(x.copy())
    
    return np.array(history)

# Rosenbrock function (challenging non-convex function)
rosenbrock = lambda x: (1 - x[0])**2 + 100*(x[1] - x[0]**2)**2
rosenbrock_grad = lambda x: np.array([
    -2*(1 - x[0]) - 400*x[0]*(x[1] - x[0]**2),
    200*(x[1] - x[0]**2)
])

# Run gradient descent
x0 = np.array([-1.0, 1.0])
history = gradient_descent_2d(rosenbrock, rosenbrock_grad, x0, lr=0.001, iters=10000)

print(f"Start: {history[0]}, Loss: {rosenbrock(history[0]):.6f}")
print(f"End: {history[-1]}, Loss: {rosenbrock(history[-1]):.6f}")
print(f"Optimum is at (1, 1)")

Using PyTorch for Automatic Gradients

import torch

# Define function
def f(x):
    return x[0]**2 + x[1]**2 + x[0]*x[1]

# Point where we want gradient
x = torch.tensor([2.0, 3.0], requires_grad=True)

# Compute function value
y = f(x)

# Compute gradient automatically!
y.backward()

print(f"Point: {x.detach().numpy()}")
print(f"Function value: {y.item()}")
print(f"Gradient: {x.grad.numpy()}")

# Verify: gradient should be [2x + y, 2y + x] = [7, 8]
print(f"Expected: {[2*2 + 3, 2*3 + 2]}")

Hessian Computation

def numerical_hessian(f, x, h=1e-5):
    """
    Compute Hessian matrix numerically
    """
    n = len(x)
    H = np.zeros((n, n))
    
    for i in range(n):
        for j in range(n):
            x_pp = x.copy()
            x_pm = x.copy()
            x_mp = x.copy()
            x_mm = x.copy()
            
            x_pp[i] += h; x_pp[j] += h
            x_pm[i] += h; x_pm[j] -= h
            x_mp[i] -= h; x_mp[j] += h
            x_mm[i] -= h; x_mm[j] -= h
            
            H[i,j] = (f(x_pp) - f(x_pm) - f(x_mp) + f(x_mm)) / (4 * h**2)
    
    return H

# Test on quadratic function
f = lambda x: x[0]**2 + x[0]*x[1] + 2*x[1]**2
point = np.array([1.0, 1.0])
H = numerical_hessian(f, point)

print("Hessian:")
print(H)
print("\nEigenvalues:", np.linalg.eigvals(H))
print("All positive → function is convex")
