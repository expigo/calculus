Integration

ML Applications

  • Probability: PDF integration gives probabilities
  • Expectation: \( \mathbb{E}[X] = \int x p(x) dx \)
  • KL Divergence: \( D_{KL}(P||Q) = \int p(x) \log\frac{p(x)}{q(x)} dx \)
  • VAEs: Use integrals for computing ELBO

Key Concepts

Fundamental Theorem of Calculus

\[ \int_a^b f'(x) dx = f(b) - f(a) \]

Common Integrals

  • \( \int x^n dx = \frac{x^{n+1}}{n+1} + C \)
  • \( \int e^x dx = e^x + C \)
  • \( \int \frac{1}{x} dx = \ln|x| + C \)
  • \( \int \sin(x) dx = -\cos(x) + C \)
